# 暗影象棋 · Shadow Chess

这是一个基于国际象棋传统规则进行了创新修改的网页版游戏。游戏采用纯 HTML, CSS 和 JavaScript 实现，具有精美的暗黑风视觉效果与完整的游戏逻辑。

## 🎭 核心玩法：暗影规则（Shadow Chess）

1. **随机开局**：双方除国王外，其余棋子在己方前两行随机打乱位置摆放（类似 Fischer Random/Chess960，但连同兵也会随机混合）。
2. **暗棋迷雾**：双方均**无法看到对方的棋子身份**，对方棋子在未揭示前显示为 “?”。
3. **首步伪装**：任何棋子在进行**第一步移动**时，必须遵循它**当前所占据的格子在传统国际象棋中原本对应的棋子走法**。
   - *例如：你的王后随机摆在马的初始格子（如 b1 ），那么第一步它只能按照“马”的规则跳跃。*
4. **翻身揭示**：棋子在走完第一步移动后，会当场翻面**揭示其真实身份**，此后该棋子将永远按照其真实规则移动。
5. **将军自动显形**：当一方在暗中对敌方国王发起“将军”时，该发起将军的棋子会自动显形以确保规则的公平。
6. **胜利条件**：吃掉对方国王，或达成传统将死（Checkmate），或对方超时。

## 🛠️ 技术特点

- **零依赖**：纯原生 JS + CSS 编写，加载极速，无任何第三方库。
- **本地双人同屏对战**：带有“传递屏幕”防偷看机制（每回合移动后有遮罩提示，由下一方确认后再显示棋盘）。
- **专业功能**：
  - 完整合规走法高亮提示（区分移动与吃子）。
  - 双人对战计时器（10分钟限时）。
  - 实时更新的代数记谱法棋谱。
  - 支持悔棋（Undo）。
  - 响应式设计，支持手机、平板和电脑。

## 🚀 启动游戏

直接双击 `index.html` 即可在浏览器中开始游玩！
